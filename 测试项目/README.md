# 测试项目导航

这里的每个子文件夹都是一套可以独立设计和本地验收的测试。文件夹名使用稳定的英文标识，中文名称写在各自的 `项目说明.md` 中。

| 文件夹 | 中文名称 | 类型 | 状态 |
| --- | --- | --- | --- |
| `moonlit-fate/` | 月下心笺 | 自定义 React 测试 | 已上线 |
| `inner-voices/` | 内在三声部 | 自定义静态测试 | 已上线 |
| `super-sbti/` | 超级 SBTI | 自定义静态测试 | 已上线 |
| `quick-recharge/` | 此刻充电方式 | 标准配置测试 | 发布中 |

新测试由 AI 创建在本目录下，并自动登记到根目录 `tests-registry.json`。不要复制整套服务器或后台，每个测试只维护自己的内容、算法、页面和素材。
