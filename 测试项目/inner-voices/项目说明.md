# 内在三声部

## 项目概况

- 英文标识：`inner-voices`
- 内容：48 题人格结构风格自我探索
- 实现方式：自定义 HTML、CSS 和 JavaScript 页面
- 公网入口：`/tests/inner-voices/`
- 兑换码前缀：`IV48`
- 当前状态：已上线

## 文件位置

- `index.html`：页面结构。
- `styles.css`、`responsive-fixes.css`：视觉与响应式样式。
- `script.js`：题目、算法、答题流程和结果。
- `test.manifest.json`：平台识别本测试所需的清单。
- `本地资料/`：本机兑换码等私密资料，不进入 GitHub。

## 修改与验收

本测试保留独立的内容、算法和页面风格，只复用平台兑换码授权。修改后应校验全部 48 题、结果计算、手机布局、兑换码门禁和重新测试流程。

本地验收完成前不上传。只有用户明确批准后，才随整个平台构建 Docker 镜像并更新 Sealos。
