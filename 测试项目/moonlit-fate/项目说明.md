# 月下心笺

## 项目概况

- 英文标识：`moonlit-fate`
- 内容：16 道心动情境题，根据答案匹配人物结果
- 实现方式：自定义 React 页面
- 公网入口：`/` 和 `/tests/moonlit-fate/`
- 兑换码前缀：`DL13`
- 当前状态：已上线

## 文件位置

- `lib/quiz.ts`：人物、题目、评分与结果依据。
- `app/page.tsx`：主要页面和答题流程。
- `app/globals.css`、`app/portrait-backgrounds.css`：视觉样式。
- `public/art/`：网站实际使用的图片。
- `test.manifest.json`：平台识别本测试所需的清单。
- `本地资料/`：原始素材、生成记录、提示词和兑换码，只保存在本机。

## 修改与验收

修改题目、评分或结果时，应同时运行题库校验和完整平台测试。修改页面时，要在电脑和手机尺寸下检查答题、返回、兑换码弹窗和结果页。

本地验收完成前不上传。只有用户明确批准后，才随整个平台构建 Docker 镜像并更新 Sealos。
